# Security Acknowledgments

Rendered into the Acknowledgments section of `/security` on dunamisstudios.com.

When a researcher submits a valid vulnerability report and wishes to be recognized, add an entry below. Sort newest first.

Entry shape:

```
## YYYY-MM-DD : Researcher name or pseudonym

- **Severity**: Critical / High / Medium / Low
- **Component**: which surface (e.g., dunamisstudios.com, atelier.exe, /api/atelier/activate-online)
- **Summary**: one-line description of the issue at the level of detail the researcher consents to publish
```
